# D8 - Alarme local + sensores extras

- [ ] D7 aprovado ou bloqueio formalmente justificado;
- [ ] cada sensor extra aprovado individualmente;
- [ ] GPIO, I2C, UART e alimentação conferidos;
- [ ] LED, buzzer e OLED identificados;
- [ ] gateway e conectividade desligados;
- [ ] estímulo de bancada seguro aplicado;
- [ ] alarme e código vieram da lógica local;
- [ ] evento, origem e qualidade preservados para sincronização.
