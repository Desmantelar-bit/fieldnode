# Checklists de bancada S8-T14

Cada arquivo corresponde a um degrau do protocolo em `docs/INTEGRACAO_HARDWARE.md`.

Os checklists são deliberadamente manuais quando dependem de placa, fonte,
instrumento, rádio ou estímulo físico. Não escreva `PASSOU` sem registrar o
resultado observado e o caminho da evidência.

Para cada execução, copie o bloco de registro abaixo e preencha os campos:

```text
data_hora=
responsavel=
placa_id=
componentes=
firmware_commit=
configuracao=
resultado=
evidencia=
falhas=
correcao=
reexecucao=
```

Teste host, captura de Serial e ensaio físico devem ser classificados
separadamente. O fato de um script sorrir para você não significa que o fio
está conectado.
